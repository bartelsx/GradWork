# Connect 4 AI – Deep Q-Network (DQN)

This is my graduation project: an AI for Connect 4 that learns to play using reinforcement learning. The AI uses Deep Q-Networks (DQN) and improves by playing against a MiniMax-based opponent.

## Features
- Deep Q-Network AI
- Self-play training against MiniMax AI
- Real-time performance feedback
- All logic implemented in C++

## Technologies Used
- C++
- Deep Q-Learning
- MiniMax AI
- Reinforcement Learning principles

## How to Run
1. Clone the repository.
2. Build the project using CMake or your preferred compiler.
3. Run the training loop or start a match.
